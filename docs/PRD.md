## 1. 产品概述

### 1.1 产品定位

CareUEyes 是一款轻量级 Windows 桌面护眼工具，通过调节屏幕色温与亮度来减轻长时间使用电脑造成的眼部疲劳。程序常驻系统托盘，采用左侧导航 + 右侧内容区的多模块界面，包含显示调节、休息提醒、专注模式、设置与关于等模块。用户可一键切换 8 种预设模式、使用番茄钟进行劳逸结合、开启专注遮罩过滤干扰，并可查看当日屏幕使用时长统计。核心显示调节支持多显示器独立控制。

### 1.2 核心原理

利用 Windows `SetDeviceGammaRamp` API 修改显卡伽马查找表（LUT），对各颜色通道（R/G/B）的输出曲线进行非线性映射，从而在不改变硬件背光的前提下模拟色温变化与亮度衰减。该方案与 f.lux、Windows Night Light 采用相同底层机制，具有以下特点：

- **零延迟**：直接写入显卡 LUT，即时生效
- **零性能损耗**：不经过渲染管线，不占用 GPU/CPU
- **兼容性强**：支持绝大多数独立显卡与集成显卡
- **可逆性**：重置伽马表即可恢复原始状态

## 3. 用户场景

### 场景一：日间办公
> 用户在白天使用双显示器工作，希望主显示器保持正常色温（6500K），副显示器略偏暖（5000K）以减轻余光刺激。通过托盘菜单分别调节两个显示器的色温。

### 场景二：夜间阅读
> 晚上用户准备阅读电子文档，点击托盘图标选择"夜间阅读"预设，屏幕立即变为 3400K 暖光 + 80% 亮度，减少蓝光刺激。

### 场景三：全屏游戏/观影
> 用户全屏观看电影时，色温调节不应造成色偏干扰。切换到"暂停"模式可临时恢复原始色温，退出全屏后自动恢复护眼设置。

### 场景四：多显示器差异设置
> 用户有笔记本外接显示器，希望笔记本屏幕保持较暖色温（因距离更近），外接显示器保持正常色温。各显示器可独立保存配置。

### 场景五：番茄钟休息
> 用户开启 45 分钟番茄钟，工作到时间后屏幕弹出全屏休息提醒，提示闭眼、远眺、转动颈部，5 分钟后自动恢复。

### 场景六：阅读专注
> 用户需要精读一份长篇 PDF，开启"阅读专注"模式，屏幕上下被半透明遮罩覆盖，仅中间保留清晰阅读区域，减少视觉疲劳。

### 场景七：屏幕使用管理
> 用户想控制每日屏幕使用时间，设置每日目标 6 小时。程序在托盘 tooltip 中显示今日已使用 5 小时 30 分，并在达到目标时弹出提醒。

### 4.2 色温调节 (P0)

| 需求编号 | FR-002 |
|----------|--------|
| 优先级 | P0 |
| 描述 | 通过滑块调节屏幕色温，范围 1900K ~ 10000K |

**详细要求：**
- 色温范围：1900K（极暖，烛光色）~ 10000K（极冷，阴天色）
- 默认值：6500K（标准日光 D65）
- 滑块步进：100K
- 实时预览：拖动滑块时即时更新屏幕色温
- 色温与 RGB 昩射关系：基于 Tanner Helland 色温算法，将色温值转换为 RGB 增益，再写入伽马表

**色温到 RGB 转换算法（Tanner Helland）：**
```
输入：色温 T (Kelvin)
输出：R, G, B 增益值 (0.0 ~ 1.0)

若 T < 6600K:
    R = 255
    G = 99.4708025861 * ln(T/100) - 161.1195681661
    若 T < 2000K:
        B = 0
    否则:
        B = 138.5177312231 * ln(T/100 - 10) - 305.0447927307
否则:
    R = 329.698727446 * (T/100 - 60)^(-0.1332047592)
    G = 288.1221695283 * (T/100 - 60)^(-0.0755148492)
    B = 255

将 RGB 归一化到 0.0 ~ 1.0 作为伽马表增益
```

### 4.3 亮度调节 (P0)

| 需求编号 | FR-003 |
|----------|--------|
| 优先级 | P0 |
| 描述 | 通过滑块调节屏幕模拟亮度，范围 20% ~ 100% |

**详细要求：**
- 亮度范围：20% ~ 100%（低于 20% 可能导致伽马表溢出/色彩失真）
- 默认值：100%
- 滑块步进：1%
- 实时预览：拖动时即时生效
- 实现方式：将色温 RGB 增益值整体乘以亮度系数，再写入伽马表
- 亮度系数与伽马表关系：`ramp[i] = round(i * brightness * r_gain)`，其中 `i` 为 0~65535

**伽马表生成逻辑：**
```python
def build_gamma_ramp(temperature_k, brightness):
    r_gain, g_gain, b_gain = temperature_to_rgb(temperature_k)  # 各通道增益
    ramp = []
    for i in range(256):
        # 每个通道 256 级，值域 0~65535 (WORD)
        r_val = int(min(65535, i * 65535 / 255 * brightness * r_gain))
        g_val = int(min(65535, i * 65535 / 255 * brightness * g_gain))
        b_val = int(min(65535, i * 65535 / 255 * brightness * b_gain))
        ramp.append((r_val, g_val, b_val))
    return ramp
```

### 4.5 开机自启 (P1)

| 需求编号 | FR-005 |
|----------|--------|
| 优先级 | P1 |
| 描述 | 程序可设置开机自动启动 |

**详细要求：**
- 通过托盘菜单勾选"开机自启"开关
- 实现方式：写入 Windows 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
- 注册表项名：`CareUEyes`，值为程序可执行文件路径
- 启动参数：`--minimized`（静默启动，直接最小化到托盘）
- 开机自启状态在程序设置中可查看和切换
- 防重复注册：启动时检查注册表项是否已存在

**注册表操作伪代码：**
```python
import winreg

RUN_KEY = r"Software\Microsoft\Windows\CurrentVersion\Run"
APP_NAME = "CareUEyes"

def set_autostart(enabled, exe_path):
    key = winreg.OpenKey(winreg.HKEY_CURRENT_USER, RUN_KEY, 0, winreg.KEY_SET_VALUE)
    if enabled:
        winreg.SetValueEx(key, APP_NAME, 0, winreg.REG_SZ, f'"{exe_path}" --minimized')
    else:
        try:
            winreg.DeleteValue(key, APP_NAME)
        except FileNotFoundError:
            pass
    winreg.CloseKey(key)
```

### 4.6 多显示器支持 (P0)

| 需求编号 | FR-006 |
|----------|--------|
| 优先级 | P0 |
| 描述 | 支持多显示器环境下各显示器独立设置色温/亮度 |

**详细要求：**
- 自动检测连接的显示器数量与名称
- 每个显示器可独立设置色温、亮度
- 显示器列表显示友好名称（如 "DELL U2720Q"）或回退到 "显示器 1/2/3..."
- 支持热插拔检测：显示器连接/断开时自动刷新列表
- 各显示器设置独立持久化
- "同步所有显示器"选项：一键将主显示器设置应用到所有显示器

**显示器枚举 API：**
```python
import ctypes
from ctypes import wintypes

user32 = ctypes.windll.user32

def enum_monitors():
    monitors = []
    def callback(hmonitor, hdc, rect, lparam):
        monitors.append({
            'handle': hmonitor,
            'hdc': hdc,
            'rect': rect
        })
        return True

    MONITORENUMPROC = ctypes.WINFUNCTYPE(
        ctypes.c_bool,
        wintypes.HMONITOR,
        wintypes.HDC,
        ctypes.POINTER(wintypes.RECT),
        wintypes.LPARAM
    )
    user32.EnumDisplayMonitors(0, 0, MONITORENUMPROC(callback), 0)
    return monitors
```

**伽马表应用 API：**
```python
gdi32 = ctypes.windll.gdi32

class GAMMARAMP(ctypes.Structure):
    _fields_ = [
        ("red", ctypes.c_uint16 * 256),
        ("green", ctypes.c_uint16 * 256),
        ("blue", ctypes.c_uint16 * 256),
    ]

def set_gamma_ramp(hdc, ramp):
    gamma = GAMMARAMP()
    for i in range(256):
        gamma.red[i] = ramp[i][0]
        gamma.green[i] = ramp[i][1]
        gamma.blue[i] = ramp[i][2]
    gdi32.SetDeviceGammaRamp(hdc, ctypes.byref(gamma))
```

| 描述 | 提供阅读专注和聚光专注两种遮罩模式，减少视觉干扰 |

**详细要求：**
- 两种子模式通过顶部 Tab 切换：
  - **阅读专注**：屏幕上下区域叠加半透明遮罩，仅中间保留透明阅读区域
  - **聚光专注**：仅鼠标周围圆形区域透明，其余区域被遮罩覆盖
- 遮罩参数：
  - 透明度：0~100%
  - 阅读专注中间区域高度：100~600 像素
  - 聚光专注光圈半径：100~500 像素
  - 遮罩颜色：默认黑色，可自定义
- 快捷键快速开启/关闭（默认 `Ctrl+Alt+F`）
- 支持预览模式，按 ESC 退出预览
- 遮罩窗口置顶、无边框、穿透非焦点区域，不影响鼠标点击
- 多显示器支持：可在所有显示器或仅主显示器上显示遮罩

### 4.13 屏幕使用时长统计 (P1)

| 需求编号 | FR-013 |
|----------|--------|
| 优先级 | P1 |
| 描述 | 记录用户每日屏幕使用时长，支持统计、目标提醒与数据导出 |

**详细要求：**
- 检测用户活动状态（鼠标/键盘输入），闲置超过 120 秒停止计时
- 显示今日已用时长：小时 : 分钟格式
- 统计维度：
  - 今日：累计时长、连续使用最长时段
  - 本周：每日柱状图
  - 本月：折线图趋势
  - 总计：自安装以来的累计时长
- 每日目标：默认 8 小时，可自定义
- 提醒机制：
  - 每连续使用 N 分钟提醒休息一次（默认 60 分钟）
  - 达到每日目标时弹出提示
  - 托盘图标 tooltip 显示今日使用时长
- 数据持久化：按日期存储到 JSON 或 SQLite
- 数据导出：支持导出 CSV / JSON（可选）
- 每日 00:00 自动重置今日计时

**数据结构示例：**
```json
{
    "screen_time": {
        "history": {
            "2026-08-17": {"seconds": 16540, "idle_seconds": 3240},
            "2026-08-16": {"seconds": 28430, "idle_seconds": 5120}
        }
    }
}
```

**活动检测 API 思路：**
```python
from ctypes import windll, Structure, c_uint, byref

class LASTINPUTINFO(Structure):
    _fields_ = [("cbSize", c_uint), ("dwTime", c_uint)]

def get_idle_seconds():
    lii = LASTINPUTINFO()
    lii.cbSize = sizeof(LASTINPUTINFO)
    windll.user32.GetLastInputInfo(byref(lii))
    millis = windll.kernel32.GetTickCount() - lii.dwTime
    return millis / 1000.0
```

### 5.3 关键技术决策

| 决策点 | 方案 | 理由 |
|--------|------|------|
| GUI 框架 | PyQt5 | 成熟稳定，QSystemTrayIcon 原生支持，信号槽机制适合实时更新 |
| WinAPI 调用 | ctypes | 无需编译 C 扩展，纯 Python 调用 gdi32/user32 |
| 配置存储 | JSON | 人类可读，无外部依赖，PyQt5 无需额外库 |
| 全局快捷键 | Windows RegisterHotKey API | 系统级注册，无需轮询键盘状态 |
| 打包 | PyInstaller | 单文件 exe，便于分发 |
| 单例机制 | Windows Mutex | 防止多实例运行导致伽马表冲突 |

### 5.4 色温调节数据流

```
用户操作（滑块/预设/快捷键）
        │
        ▼
  PresetManager / UI
        │  temperature_k, brightness
        ▼
  GammaController
        │  1. temperature_to_rgb(T) → (r_gain, g_gain, b_gain)
        │  2. build_ramp(r_gain, g_gain, b_gain, brightness) → ramp[256]
        ▼
  DisplayManager
        │  遍历每个显示器的 HDC
        ▼
  SetDeviceGammaRamp(hdc, ramp)
        │
        ▼
  屏幕色温即时变化
```

## 9. 风险与对策

| 风险 | 影响 | 概率 | 对策 |
|------|------|------|------|
| SetDeviceGammaRamp 在部分显卡驱动上不生效 | 高 | 中 | 提供 DDC/CI 亮度控制作为备选方案；检测失败时提示用户 |
| 远程桌面 (RDP) 不支持伽马表 | 中 | 高 | 检测 RDP 环境时禁用功能并提示用户 |
| HDR 模式下伽马表被系统覆盖 | 中 | 中 | 检测 HDR 状态，提示用户关闭 HDR 或使用 Windows 夜间模式 |
| 程序异常退出未恢复伽马表 | 高 | 低 | atexit 钩子 + 异常信号捕获 + 下次启动检测残留并恢复 |
| 多实例运行导致伽马表冲突 | 中 | 低 | Windows Mutex 单例锁 |
| Windows 更新修改伽马表机制 | 高 | 低 | 预留抽象层，支持切换到 DDC/CI 或其他后端 |
| 专注遮罩窗口拦截系统操作 | 中 | 低 | 设置遮罩窗口 WS_EX_TRANSPARENT，确保只遮挡视觉不拦截输入 |
